# זיהוי תנועת מטופל ממצלמת הקשת

המצלמה מסתובבת עם הקשת. מיקום המצלמה בכל פריים מחושב מה-encoder דרך מודל הקשת, ולכל זוג
פריימים סמוכים בודקים את הנקודות על הגוף:

- **הקשת זזה:** בדיקה אפיפולרית. בסצנה סטטית כל נקודה חייבת להופיע על קו מסוים בפריים הבא, וסטייה
  מהקו פירושה תנועה. הפרלקסה כבר כלולה במודל, ולכן היא לא נראית כמו תנועה.
- **הקשת עומדת (אותה זווית):** השוואה ישירה. כל הזזה עקבית של אזור בגוף היא תנועה. זה המצב הרגיש
  ביותר: על הפאנטום רמת הרעש כ-0.02 מ"מ.

**סינונים:**
- נספרות רק נקודות על הגוף (סגמנטציית אדם) **שנמצאות מעל הגלאי**.
- התרעה נוצרת רק **בחלון ההקרנה**: מסוף העצירה בזווית ההתחלה ועד תחילת העצירה בזווית הסוף. התנועה
  מ-HOME לזווית ההתחלה והחזרה ל-HOME מחושבות ומוצגות בגרף, אבל לא מתריעות.
- זוגות פריימים שבהם מהירות הקשת משתנה ביותר מ-30% (התחלה, עצירה או היפוך) מדולגים. שם הפער בזמן בין
  התמונה ל-encoder גדול מדי.

הבדיקה סיבתית: היא משתמשת רק בפריים הנוכחי ובפריים הקודם, ולכן אפשר להריץ אותה בזמן אמת.

## מבנה התיקייה

```
motion/
  calib.py      כיול ה-fisheye (פורמט CalibrationResult של ARC22), כולל undistort מדויק
  scan.py       טעינת סריקה, זווית לכל פריים, חלוקה לשלבים וחלון ההקרנה
  gantry.py     מודל הקשת (מצלמה שמסתובבת סביב ציר קבוע), התאמה ומטריצה אסנציאלית
  masks.py      סגמנטציית אדם (YOLOv8m-seg), מסכת פאנטום, השתקפויות
  roi.py        אזור הגלאי: מוגדר על פריים HOME ומועבר לכל פריים דרך הומוגרפיה של המיטה
  tracking.py   מעקב KLT עם בדיקה קדימה-אחורה
  rigidity.py   הציונים לזוג פריימים
scripts/
  evaluate_scan.py   הסקריפט הראשי
  fit_gantry.py      התאמת מודל הקשת מסריקה סטטית
  run_all.sh         משחזר את כל התוצאות ב-results/ ושומר את המסכות
  run_experiments.sh משחזר את ניסויי אוקטובר על המסכות השמורות
  inspect_cluster.py מציג את 30 הנקודות שקבעו ציון, ובודק אותן
  show_residuals.py  תמונה של השארית לכל נקודה בזוג פריימים
  breathing.py       ניסיוני: אות נשימה
data/
  CalibrationResult_arc22.json
  gantry_arc22.json  מודל הקשת של ARC22
results/             CSV וגרף לכל סריקה שנבדקה
```

## התקנה

```
pip install -r requirements.txt
```

בהרצה הראשונה ultralytics מוריד את `yolov8m-seg.pt` (כ-55MB).

## שימוש

```
python scripts/evaluate_scan.py --scan <scan.zip|folder> \
    --calib data/CalibrationResult_arc22.json --gantry data/gantry_arc22.json \
    --detector-mask detector_home.png  --out results/scan.csv --plot results/scan.png
```

| פרמטר | ברירת מחדל | משמעות |
|---|---|---|
| `--detector-mask` | | תמונת PNG בגודל 1280x720 על פריים HOME, לבן = מעל הגלאי. אפשר במקומה `--detector-rect x,y,w,h` |
| `--cluster-k` | 16 | גודל האשכול של הציון: חציון השארית של k נקודות שכנות (8, 16 או 30). עד אוקטובר 2026 היה 30. ראו `results/cluster_size_2026_10/` |
| `--threshold` | 0.5 px | סף בזמן שהקשת זזה (ציון האשכול). בערך 1.1 מ"מ במישור המיטה |
| `--static-threshold-mm` | 0.5 | סף כשהקשת עומדת |
| `--persistence` | 1 | מספר הזוגות הרצופים מעל הסף שנדרש להתרעה |
| `--all-phases` | | להתריע גם במהלך התנועה מ-HOME ובחזרה |
| `--from-csv` | | לא מעבד תמונות. מפעיל מחדש רק את כלל ההחלטה ואת הגרף על CSV קיים, ומתאים לכיוון ספים |
| `--label` | | טווח מתויג לגרף, למשל `63-85` |
| `--save-masks` | | תיקייה לשמירת המסכות שבהן ההרצה השתמשה בפועל (ראו בהמשך) |
| `--body-masks` | | שימוש במסכות שמורות במקום סגמנטציה, כדי שהמסכה תהיה זהה בין ניסויים |
| `--detect` | global | `global`, `masked` או `masked_abs`. אופן בחירת נקודות הגוף |
| `--body-fb-max` | 0.5 | מגבלת forward-backward לנקודות גוף |
| `--guard` | legacy | `legacy`, `time`, `bg` או `none`. בדיקת אמינות הגאומטריה |
| `--guard-action` | drop | `drop`: זוג לא אמין לא מתריע. `mark`: מתריע ומסומן כלא אמין |
| `--bed`, `--min-bed`, `--guard-bed-px` | | בדיקת הגאומטריה לפי נקודות מישור המיטה ליד ה-ROI (`--guard bed`) |
| `--roi-fixed` | | ROI קבוע בקואורדינטות התמונה |

**שני שיפוטים נפרדים לכל זוג:**
- `motion_state`: `SUSPECT`, `NO_MOTION` או `NO_BODY_DATA`.
- `geometry_state`: `VERIFIED`, `UNRELIABLE`, `BG_MISSING` או `NOT_CHECKED`.

`label` הוא טקסט קריא, למשל "motion suspected; background missing for verification". `alarm_any` כולל כל חשד, גם בלי רקע לאימות. `alarm_confirmed` כולל רק חשד שהגאומטריה שלו אומתה.

פירוט הניסויים: `results/experiments_2026_10/`, `results/background_study_2026_10/` ו-`results/bed_validation_2026_10/`.

בכל הרצה נשמר ליד ה-CSV גם `<name>.settings.json`. הקובץ כולל את שורת הפקודה, כל הפרמטרים (גם ברירות
המחדל), ה-commit, גרסאות הספריות, ה-hash של משקולות הסגמנטציה ושל קובץ הכיול, ואת מודל הקשת.

## שחזור התוצאות

```
bash scripts/run_all.sh <scans_dir> [results] [masks]
```

`<scans_dir>` צריכה להכיל את חמש תיקיות הסריקה (או קבצי ZIP באותם שמות). השמות מופיעים בראש הסקריפט.
ההגדרות של כל התוצאות:

| הגדרה | ערך |
|---|---|
| סגמנטציה | `yolov8m-seg.pt`, conf 0.25, imgsz 960, התמונה מסובבת ב-90 מעלות |
| כיווץ מסכה | 21 פיקסלים |
| סף בזמן תנועת הקשת | 0.5 px על `epi_enc_cl30` (בהרצות הראשונות; כיום `epi_enc_cl16`) |
| סף כשהקשת עומדת | 0.5 מ"מ |
| persistence | 1 |
| sync | 0.9 |
| אזור הגלאי | `--detector-rect 280,150,620,375`, **הערכה זמנית** |

## המסכות (`--save-masks`)

לכל פריים a נשמרות שלוש תמונות. כל אחת מתארת את מה ששימש לזוג a→a+1:

| קובץ | תוכן |
|---|---|
| `body_<frame>.png` | מסכת הגוף אחרי הכיווץ, לבן = גוף |
| `used_<frame>.png` | האזור שבו נקודות באמת נספרו: גוף, בלי השתקפויות, ובתוך אזור הגלאי |
| `view_<frame>.jpg` | תצוגה בחצי גודל. אדום = האזור שנספר, תכלת = גבול אזור הגלאי |

**יחידות:** הפיקסלים הם של התמונה המתוקנת בחצי רזולוציה. פיקסל אחד הוא בערך 2.2 מ"מ במישור המיטה.

## תוצאות

אזור הגלאי בתוצאות האלו הוא **הערכה**: המלבן בין ארבעת הריבועים הלבנים (`--detector-rect 280,150,620,375`).

| סריקה | מה קרה | התרעות בחלון ההקרנה |
|---|---|---|
| A28_1 | תנועת חזה מכוונת; הטווח המתויג הוא 63–86 | 62–86 |
| | התרעות מחוץ לטווח המתויג, **לא מאומתות** כתנועה | 106–110 |
| A26 | תנועת יד קטנה, 3–5 מ"מ | 61, 68 |
| רגליים, סטטי | | אין |
| VC01 עצירת נשימה | | אין |
| VC01 נשימה רגילה | | אין |

- **מרווח צר מאוד:** תנועת היד הגיעה ל-0.54–0.60 px. הציון הגבוה ביותר בסריקות הסטטיות הוא 0.496 px
  (עצירת נשימה, פריים 108), כמעט בדיוק על הסף. הציון הזה לא נובע מתנועה: הוא מגיע מנקודות בתפר בין היד
  לגוף. שם יש קפיצת עומק בתוך המסכה, והכיווץ לא מוריד אותה.
- **רמת רעש כשהקשת עומדת:** בפאנטום 0.02 מ"מ (חציון), 0.09 מ"מ באחוזון ה-95. במתנדב "סטטי" 0.17–0.25 מ"מ,
  שזו כנראה תנועה אמיתית קטנה של הגוף.
- **נשימה:** לא מזוהה בזמן שהקשת זזה.
- **אזור הגלאי עוקב אחרי מישור המיטה:** ההומוגרפיה מחושבת רק מנקודות על המיטה ליד האזור. בגרסה הקודמת
  היא חושבה מכל הרקע, כולל הרצפה, והאזור זז בכ-9 ס"מ בזווית של 16 מעלות.

## התאמה מחדש של מודל הקשת

```
python scripts/fit_gantry.py --scan <static_scan> --calib data/CalibrationResult_arc22.json \
    --first 40 --last 110 --out data/gantry_<machine>.json
```
